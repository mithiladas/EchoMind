# EchoMind
An Audio-Based Memory Game for the Visually Impaired — Built with Python

**EchoMind Game** is an inclusive and interactive **audio-based game** designed especially for **visually impaired players**.  
The game tests the player’s **auditory memory** by playing a random sequence of sounds — such as **bell**, **clap**, **whistle**, or **drum** — which the player must remember and reproduce in the correct order.  
With every new level, the sound sequence grows longer, making the challenge progressively harder and fun!  

This project demonstrates how Python can be used to create **accessible, sound-driven games** that provide entertainment without relying on visual elements.  

Technologies Used
1. Python 3.x
2. Pygame – for sound playback
3. Random & Time modules – for sequence and timing control

Project Structure
SoundMemoryGame/
│
├── game.py
├── bell.wav
├── clap.wav
├── whistle.wav
└── drum.wav

Gameplay
1. Listen carefully to the sequence of sounds.
2. Type the names of the sounds (e.g., bell clap) in the correct order.
3. If correct, you move to the next level with a longer sequence.
4. A single mistake ends the game!
